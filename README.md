# HTML-and-CSS-Task
Making a simple landing page using HTML and CSS
SLABVAULT — Landing Page
Landing page sederhana untuk jasa grading & autentikasi kartu koleksi.
Dibuat untuk tugas Landing Page menggunakan HTML & CSS.
🔧 Dibuat dengan

HTML5 (semantic)
CSS3 murni — External CSS (tanpa framework, tanpa JavaScript)
Google Fonts: Fraunces (display) & Hanken Grotesk (body)

✨ Fitur

Desain dark, responsif (desktop → mobile)
Kartu holografik dibuat full pakai CSS (conic-gradient + animasi shine & float)
Animasi reveal saat halaman dimuat (staggered)
Hover interaktif pada kartu harga, fitur, dan langkah
Menghormati prefers-reduced-motion

📁 Struktur file
landing-page/
├── index.html   # struktur halaman
├── style.css    # styling (external CSS)
└── README.md



▶️ Cara menjalankan
1. Download / clone folder ini.
2.Pastikan index.html dan style.css ada di folder yang sama.
3. Buka index.html lewat browser (double-click) — selesai.
